# Tripadvisor-clone

A responsive **TripAdvisor-inspired travel website clone** built using **HTML5 and CSS3**. This project recreates the look and feel of a modern travel platform with destination discovery, travel activities, restaurant listings, search, and travel inspiration sections.

## 🚀 Features

* Responsive navigation bar
* Travel destination search section
* Popular destination cards
* Things-to-do section
* Restaurant listings
* Travel inspiration/articles section
* Responsive design for desktop, tablet, and mobile
* Hover effects and modern card-based UI
* Clean and beginner-friendly HTML & CSS

## 🛠️ Technologies Used

* HTML5
* CSS3
* CSS Flexbox
* CSS Grid
* Responsive Media Queries
* Google Fonts
* Unsplash Images

## 📂 Project Structure

```text
traveladvisor-clone/
│
├── index.html
└── style.css
```

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. For easier development, use the **Live Server** extension in VS Code.

## 🎯 Purpose

This project was created as a **frontend development practice project** to improve skills in HTML, CSS, responsive layouts, Flexbox, Grid, and website UI design.

> This is an educational project inspired by the design and structure of travel websites and is not affiliated with TripAdvisor.
